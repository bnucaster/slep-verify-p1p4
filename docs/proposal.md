# Proposal · Measuring Semantic Energy: A Preregistered Empirical Test of the Semantic Least-Energy Principle

申请方向：SLEP 方向 1，母论文 4.7 节（预测协议）四条预测的首次系统实证检验。详细协议见附件《综合实验方案 v2》；本件为摘要、计划与预算。

## 1. 项目摘要

母论文以预注册格式给出四条可证伪预测。本项目在三个测试系统上独立检验其中四条：P1（能量随学习下降、拟合后压缩）、P2（推理轨迹集中于低作用量路径）、P3（低梯度区审议轨迹近测地）、P4（自信息对势的 Boltzmann 仿射律与温度可辨识）。判定按系统三值记账（通过 / 失败 / 未构成检验）：全过为纲领背书，分裂给出适用边界地图，全败构成高规格证伪，任何格局可成文。交付物为一篇论文、开源估计器工具箱、带外部时间戳的预注册协议与机器可读的判定记录。

## 2. 技术路线（摘要）

测试系统三个：S1（β-VAE / dSprites，服务 P1 与 P4 静态支线）、S2（GRU 循环世界模型 / 部分可观测网格世界，推理轨迹取模型自身内部更新映射的演化，服务 P2、P3、P4）、S3（小型 Transformer 最小版，只跑 P1，回应架构普适性）。

估计器层在潜空间上实现度量、势、熵、自信息（含体积校正）、OM 作用量、测地偏差、经验漂移分解与支撑度诊断；温度只从 P4（仿射律）斜率估出。

协议纪律：合成真值校准定噪声地板与阈值公式 → 开发族（种子 0–4）描述性测绘 → 协议冻结并外部时间戳（OSF 或仓库哈希）→ 评估族（种子 5–9）确证，入域门（能力、几何、平稳）先于判定，判定由冻结代码写入 metrics JSON。每条预测双层判据：母论文原判据照测照报，本方案增补对照（P4 频率解耦、P2 势项消融、P3 对照规划器、P1 零模型对照）另列，标题级结论要求两层同时成立。

## 4. 预算（英镑计价）

### 4.1 计价假设

1. 平台与规格：RunPod Secure Cloud（数据中心级、无抢占）按需租用；参照卡为 RTX 4090 24GB，标价 0.69 美元/小时；按秒计费，出网流量免费。分析类非吞吐瓶颈作业可下放 RTX A5000 24GB（0.27 美元/小时），预计再省一至两成（推断，未计入下表）。价格为 2026 年 8 月 23 日对 RunPod 官网及多家第三方价目的核对结果，云价随时变动，签约前应复核。
2. 存储：网络卷 0.07 美元/GB/月，按 200–300 GB × 6 个月计。
3. 汇率：1 美元 = 0.733 英镑（2026 年 8 月 23 日中间价）。汇率与美元标价的波动由申请额度上浮吸收。

5. 税务：以上为平台标价、未含税；英国法人采购境外云服务的增值税处理请财务按反向征收规则核实。
