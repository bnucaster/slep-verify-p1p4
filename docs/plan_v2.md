# SLEP 方向 1 · P1–P4 实证检验：综合实验方案（修订二稿）

拟题：**Measuring Semantic Energy: A Preregistered Empirical Test of the Semantic Least-Energy Principle**

定位：单篇论文，正面检验母论文 4.7 节（预测协议）预注册的四条预测：P1（能量随学习下降、拟合后压缩）、P2（推理轨迹集中于低作用量路径）、P3（低梯度区审议轨迹近测地）、P4（自信息对势的 Boltzmann 仿射律与温度可辨识）。P5（跨模态对齐）留给方向 8。四条预测按系统独立判定、三值记账（通过 / 失败 / 未构成检验）：全过为纲领背书，分裂为适用边界地图，全败为高规格证伪，任何格局可成文。

相对初版方案的主要修订：

1. 描述性实验成为正式阶段并前置，预注册挪到描述之后、接触评估族之前；
2. 新增入域门与三值记账，把"理论失败"与"系统在适用域外"分开；
3. P1（能量下降）主判据改为熵分量；P2（低作用量）主代理改为平滑随机路径并加势项消融；P3（近测地）加支撑度诊断与对照规划器；P4（仿射律）加频率解耦对照；
4. 确证执行序按估计依赖排：P4（仿射律）最先（温度上游），P2（低作用量）最后；
5. 各协议的判定统一为两层：母论文原判据照测照报，本方案增补判据另列，标题级结论要求两层同时成立；
6. 预算重估为 8–12 GPU 周；原拟单独发的方法学内容并回本篇。

## 2. 测试系统、能力阶梯与数据分族

**S1 · β-VAE / dSprites 因子世界**。数据 dSprites（真值因子已知），潜维 8；β∈{1, 4}，Adam 1e-3，密集检查点（前期对数间隔、后期每 2k 步）。服务 P1（能量下降）与 P4（仿射律）的静态支线；真值因子支持效用探针。

**S2 · 循环世界模型 / 部分可观测网格世界**。程序生成迷宫导航，观测为局部视野图像；备摆杆连续控制变体。GRU 世界模型（编码器 + 循环更新 + 观测解码器），循环更新即母论文 Setting 1（系统七元组设定）中的内部更新映射 Ψ；推理轨迹是模型自身隐状态的演化，避免用自建积分器验证自建动力学的循环。潜维 8–16。规划段（P3 用）以 CEM/MPC（交叉熵方法 / 模型预测控制）产生固定端点的审议轨迹；新奇注入（P2 用）在已知时刻切换未见迷宫拓扑或扰动物理参数，新奇锚取 OOD（分布外）基准成员资格，独立于能量估计。

**S3 · 小型 Transformer 序列世界模型**。保留最小版，只跑 P1（能量下降），回应架构普适性追问；削减时最后砍。

能力阶梯：S1（β-VAE）、S2（世界模型）各训 3 档容量或训练时长。阶梯符合度测绘在开发族上做（探索性质）；评估族只训练并运行在开发族上过入域门的档位，每档用校准系统重估估计器噪声地板。

采样纪律：S2（世界模型）采推理轨迹前参数冻结，对应母论文 D11（双时间尺度定义）中推理尺度参数不变的要求。

## 3. 入域门与三值记账

动机：母论文的公理只在正则条件下有预测力。A3（推理尺度潜态服从漂移为负势梯度的 Langevin 方程这一公理）预设势场与度量良定义；A1（学习尺度带效用约束的自由能下降公理）预设约束可行。前提不满足时预测失败没有信息量。门先于判定执行，未过门记"未构成检验"，与"失败"分开记账。

1. 能力门：效用 Û（S1 为冻结检查点上因子探针的留出精度；S2 为留出迷宫导航成功率）超过预先定死的绝对阈值。
2. 几何门：访问区域上度量估计 ĝ 的条件数有界，有效潜维稳定；防 β-VAE 在 β=4 下维度坍缩使度量近奇异，连带测地求解与体积校正失效。
3. 平稳门（P4 仿射律专用）：多条独立链的分布一致性诊断，替代单链分段 KS 检验（分布一致性检验）。
4. 测地唯一性认证（P2、P3 用）：多起点测地求解收敛到同一路径类才纳入分析；偏差取到最近一条的距离；求解器残差作质检量报告。防迷宫潜流形多条近最短路径使偏差无唯一定义。

## 4. 估计器层

| 量 | 含义 | 估计方法 | 自检 |
|---|---|---|---|
| ĝ(z) | 潜点 z 处的 Fisher 度量估计 | 解码器 Jacobian 拉回（高斯解码器闭式）；MC 得分协方差交叉验证；另以异种子解码器副本估一版，打断与 V̂ 的噪声共享 | 线性闭式对拍 |
| V̂(z) | 语义势估计：z 邻域局部观测律上解码负对数似然的均值 | 潜空间 k 近邻球，报告 k 敏感性；第二操作化为编码器后验加权 | 合成真值恢复 |
| Ê(z) | 无量纲化能量 | Ê = V̂ / V̂_ref，V̂_ref 为参考模型（初始化）的同类势值；换随机重启参考做鲁棒性 | 参考更换 |
| p̂(z)、Ŝ | 潜态密度估计与熵估计 | kNN（k 近邻）熵估计器与 normalizing flow（归一化流）双路互证 | 已知高斯流形恢复解析熵 |
| Î(z) | 相对不变测度的自信息 | Î = −log p̂(z) + (1/2)·log det ĝ(z)，对应母论文 C2.1（密度须相对不变测度取） | 同上 |
| T̂ | 语义温度估计 | 只能来自 P4（仿射律）拟合斜率的倒数，对应母论文 C4.1（斜率倒数估温度） | CAL-P4 恢复真温度 |
| F̂_S | 自由能估计 | F̂_S = ⟨V̂⟩ − T̂·Ŝ，⟨·⟩ 为对潜态分布取平均 | — |
| Â_OM | OM（Onsager–Machlup）作用量估计 | 主项 (1/4T̂)·∫‖ż + ∇_ĝV̂‖²_ĝ dt 离散化：ż 为潜态速度，∇_ĝ 为 ĝ 度量下的梯度，‖·‖_ĝ 为该度量下的范数；R 修正项报为 O(T) 不确定度 | 合成 Langevin 恢复 |
| 测地偏差 | 轨迹对同端点数值测地线的归一化偏差面积 | 多起点直接作用量最小化，取最近路径 | 平坦度量下退化为直线偏差 |
| 漂移分解 | 经验漂移场的梯度占比 | 轨迹回归漂移场，在 ĝ 度量下做梯度 / 无散分解 | 合成梯度流占比趋 1 |
| 支撑度 | 沿轨迹的估计可靠性 | 近邻半径诊断；低支撑段剔除规则预注册 | — |

三个组合量的直观含义。Î 的体积校正：p̂ 是相对坐标体积的密度，除以流形体积因子（即减去 −(1/2)log det ĝ）换算成相对流形不变体积的密度后，自信息才是坐标不变量；漏掉此项，P4（仿射律）的横纵轴依赖参数化。F̂_S：平均代价减温度加权的分散度，是母论文 D10（自由能泛函定义）在样本上的直接估计。Â_OM：路径速度对负势梯度漂移的偏离的累计平方代价，数值越低表示路径越接近该随机动力学最可能实现的走法。

## 5. 校准阶段（第 1 月）

1. 在校准种子上短程试点 S1（β-VAE）、S2（世界模型），提取 ĝ 的谱与各向异性，据此构造几何匹配的合成系统；禁止在规整高斯流形上过检，那样得到的是虚假信心。
2. CAL-P4（在已知势、度量、温度上模拟 Langevin 的合成校准系统）：全链应恢复仿射律与真温度，误差带公式化为 P4（仿射律）容差。另做两件：注入同源噪声（度量与势共用一套解码器噪声），验证管线不凭空造出仿射；推导观测噪声调大后 Î–V̂ 斜率的预期签名，供确证阶段操纵检查判向。噪声同时抬升 V̂，两轴同变时 T̂ 未必朴素上升，签名须预先推出。
3. CAL-P2/P3（合成最小作用量系统）：量出 Â_OM 分位与测地偏差的噪声地板，效应量阈值由此公式化；给多起点测地求解定残差基准与唯一性认证流程。
4. CAL-P1（构造性两相 / 无两相学习曲线）：定标平台检测器参数。
5. 仪器门：任何一环恢复不了已知真值，停下修估计器再前进；此分支写入预承诺页。

## 7. 冻结与预注册（第 2 月末）

协议 v1.1 内容：

1. 全部阈值由校准与描述阶段的公式导出，无手拍数；
2. 入域门三件（能力、几何、平稳）与测地唯一性认证先于判定执行，未过门记"未构成检验"；
3. 聚合规则：每条预测按覆盖系统分别判定；标题级"支持"要求全部过门系统通过，任一过门系统失败即该条预测计失败。S1（β-VAE）的 P4 支线为静态潜态统计（无内部更新映射，测的是编码频率对代价的静态关系），标为类比，只供该系统 T̂ 输入，不进 P4（仿射律）判定；
4. 降级预案预先写死：某系统 T̂ 不可辨识（仿射被拒或分半超容差）时，该系统 P1（能量下降）判定落在 Ŝ 与 ⟨V̂⟩，F̂_S 只作描述性曲线。P2（低作用量）受牵连有限：主判定是观测对代理的分位排序，Â_OM 主项中 1/4T̂ 对同系统全部路径是公共正因子，排序与 T̂ 无关；
5. 每条预测的失败判据沿母论文 4.7 节（预测协议）原文，本方案增补判据另列；
6. 探索性与验证性分析分开标注，前者不进裁决。

时间戳用 OSF（开放科学框架）或公开仓库提交哈希，内部签字不足以对外。判定代码冻结，结论由代码写入 metrics JSON；评估阶段人的角色只剩运行代码。

## 8. 确证阶段（第 3–5 月）

评估族按冻结配置训练。执行序：EXP-P4（仿射律）→ EXP-P1（能量下降）与 EXP-P3（近测地）并行 → EXP-P2（低作用量）。依据：T̂ 是上游量；P2 对照负担最重。

### EXP-P4 · 仿射律与温度（S2 主 + S1 静态支线；平衡统计）

1. S2（世界模型）平稳环境长程自由运行（≥10⁶ 步），平稳性用多链一致性诊断；
2. 网格 / 子采样状态点上算 Î（体积校正后）与 V̂；
3. 仿射判定：线性拟合对二次备择；预注册 lack-of-fit：二次项 F 检验 p>0.05 且 ΔBIC（贝叶斯信息准则之差，线性减二次）< 2；R²（拟合优度）超预注册下限；
4. 温度：T̂ = 斜率倒数；分半一致性 |T̂₁ − T̂₂| / T̄ < 20%，分半取时间前后两段与两独立运行双口径；
5. 解耦对照（判定有效性的核心）：其一，解码器在均匀采样状态上训练、访问分布仍由策略产生，对比策略访问数据训练的解码器；其二，冻结解码器更换探索策略，斜率应不随策略变。斜率随占据统计漂移即说明相关来自"见得多所以拟合好"；
6. 盆地结构：潜态聚类后盆地内分段拟合加斜率同质性检验；"共同斜率、不同截距"是比全局仿射更锐利的预测，可区分混合不足与理论失败；
7. Î 含 / 不含校正双版本、异种子度量副本并报；
8. 噪声操纵：按 CAL-P4（合成校准）预推的签名判向。

失败判据（母论文原文）：lack-of-fit 拒绝仿射，或分半 T̂ 超容差。本方案增补：解耦对照失败（斜率随策略变）单列报告，判定该系统 P4 的表观仿射不构成支持。

### EXP-P1 · 能量随学习下降、拟合后压缩（S1 + S2 + S3 最小版；学习尺度）

1. 逐检查点算 ⟨V̂⟩（留出同分布集）、Ŝ、Û、Ê。平台检测规则用冻结版：Û 滑窗斜率连续 3 窗 < 1%/窗 → 平台点；平台后窗口 = min(2×平台点, 训练总长)；
2. 判定两层。母论文原判据：F̂_S 与 ⟨V̂⟩ 沿学习时间非增（种子噪声带内波动允许，带宽由开发族定），平台后 ⟨V̂⟩ 下降超预注册最小效应且 Û 保持平台带。本方案主判据：平台后窗口内 Ŝ 下降超噪声地板且 Û 保持平台带。标题级"通过"要求两层同时成立；F̂_S 判定条件于该系统 T̂ 可辨识；
3. 对照：随机标签训练（效用约束不可满足，预测两相结构消失或畸变）；参考模型更换鲁棒性；
4. 正文明示平凡零模型的预测范围（重构项随随机梯度下降持续降低），增量只归给零模型不预测的部分（效用平台后的熵压缩）。

失败判据（母论文原文）：⟨V̂⟩ 平台后停滞或上升。

### EXP-P3 · 低梯度区审议轨迹近测地（S2 规划段；推理尺度）

1. 梯度分区从 V̂ 场独立预定（‖∇_ĝV̂‖ 下 / 上三分位），独立于轨迹拟合，满足外部锚要求；
2. 收集端点条件化的 CEM/MPC（交叉熵方法 / 模型预测控制）审议轨迹，按穿越区域分组，端点距离与时长匹配；
3. 低支撑段按预注册规则剔除（近邻半径超阈值）；
4. 每条轨迹对同端点数值测地线（多起点、唯一性认证通过者，取最近路径）算归一化偏差。判定：偏差(低梯度) < 偏差(高梯度)，Mann–Whitney（秩和检验）p<0.01 且效应量超校准定出的最小可检测差；偏差与 ‖∇_ĝV̂‖ 正关联；
5. 对照规划器：随机射击与匹配平滑度的变体，区分规划器优化产物与地形结构；
6. 地形过平（分位差落入噪声地板）记"检验未运行"。

失败判据（母论文原文）：低梯度区测地偏差不小于匹配的高梯度区。

### EXP-P2 · 轨迹集中于低作用量路径（S2；推理尺度）

1. 平稳环境收集 ≥1000 条推理轨迹（模型自身内部更新映射 Ψ 的演化）；
2. 每条观测轨迹配 ≥50 条端点匹配代理。主代理：长度与速度分布匹配的平滑随机路径。桥插值、时间打乱拼接、相位随机化降为稳健性检查：三者均比真轨迹粗糙，任何光滑动力系统都能在与它们的对比中"集中"，不可作主判据；
3. 集中性判定：观测轨迹 Â_OM 中位数落在其代理分布下四分位以下，跨轨迹比例 > 75%；
4. 势项消融（SLEP 特异判别）：同批路径分别按含 ∇_ĝV̂ 与势取常数的 Â_OM 打分；含势版本的分辨力显著高于常数势版本，才能把"集中"归给势结构；

6. 新奇关联降为一致性检查：OOD（分布外）注入步的偏离增量与新奇指示的正关联（逻辑回归 p<0.01），保留新奇时刻随机平移的安慰剂检验。
