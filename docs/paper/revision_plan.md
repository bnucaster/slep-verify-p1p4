## 0. 一处对审稿前提的澄清(据实,非辩护)

审稿判 §5.2 "six orders of magnitude" 为数值错误。核对源码
(scripts/run_geom_decomposition.py 第 52 行)与产物:文中 2.95–3.09、
9.0–9.6 是 **log10 条件数中位**,不是条件数本身。故条件数由 ≈10^9.4
降到 ≈10^3,比值 ≈10^6.4——"六个数量级"对条件数本身成立。问题在草稿
把 log10 值直接称 "condition-number median" 未标 log10,读起来与 3、9.4
这两个数矛盾。这是标注歧义,处理见 B3(改标注,保留正确的量级结论,并补
机制证据)。审稿人的底层担忧(内部不一致)成立,照改。

## A. 补充实验

### A1 · 解码器 Jacobian 谱与有效秩(对应 critical 3 后半 + 附注的因果性质疑)

意图:审稿要求把"未用记忆维经多步头对观测可见"从假说落成直接测量。
- 对 S2(基线)、S2P、S3(v1 无多步头 / v2 有)在分析检查点,逐潜维算解码器
  Jacobian J 的奇异值谱、有效秩(参与比 (Σσ)²/Σσ²)、逐潜维解码敏感度
  (‖∂μ/∂z_i‖)。
- 预期:S2 与 S3-v1 的谱有若干近零奇异值(记忆维不可见)、有效秩低;
  S2P、S3-v2 谱抬升、有效秩升。若与"记忆维可见性"假说一致,则机制由
  假说升为测量;若不一致,则把 §5.2 的机制表述降级为假说并如实说明。
- 成本:低。模型与 estimators.metric(Fisher 拉回 = JᵀΣ⁻¹J,可直接取 J 奇异值)
  已在;新增一图。产物落 results/description/jac_spectra/。

### A2 · P2 的种子级统计(对应 critical 2 的推断单元质疑)

意图:审稿指出 Wilcoxon 在 1000 条轨迹上做(轨迹级),而归因是种子级。
- 从已缓存的逐轨迹配对差(exp_p2/eval_v1/s*/main_cache 与 abl_cache)
  重聚合到种子级:每种子的中位配对差(5 个值)+ 自助置信区间;跨 5 种子
  的符号检验 / Wilcoxon;逐种子效应量与不确定度并报,与轨迹级 p 值并列。
- 同法给集中性(低于 Q1 比例)与新奇关联的种子级汇总。
- 成本:低。纯重聚合已缓存数据,无重跑;更新 fig(P2)与正文表。

### A3 · P2 对代理构造与数值选择的稳健性(对应 critical 2 的稳健性要求)

意图:审稿要求换合理的替代代理与 ĝ/∇V̂ 数值选择复核结论方向。
- 代理替代:除度量口径平滑随机代理(主口径),另跑协议里列为稳健性检查的
  桥插值(bridge interpolation)与相位随机化(phase randomization)各一,
  在每种子 200 条子样本上复算集中性与消融配对差方向。
- 数值替代:V̂ 的 k(32→16、64)、度量地板 metric_floor_rel(1e-3→1e-2)
  各一档,复核集中与消融是否同向。
- 报告:通过/不通过的方向一致性,不改主口径判定(判定仍取冻结口径)。
- 成本:中(子样本 + 少数档),约半日算力;逐块缓存断点续跑。

### A4 · 新鲜预注册的 P2 确证复制(可选,对 critical 1 最强的正面回应)

意图:审稿核心是 P2 pass 是修订后、见过聚合结果的产物,确证力弱。最硬的
回应是给一个未接触过的实例上的新鲜确证。
- 冻结一份 v1.3 增补,把 S2P 的 P2 全管线(代理算法、端点匹配容差、平滑、
  速度分布匹配、离散化、ĝ 病态处理)完整写死并取外部时间戳;
- 在一个全新未用实例上运行:换迷宫生成偏移 / 新环境种子族 / 新任务分布
  (与 eval 5–9 无重叠),作真正的样本外确证;通过则 P2 由"修订后"升为
  "新鲜预注册确证",两者并报。
- 成本:高(需新训练 + 评估,约一至两日算力),且须用户拍板是否做。属可选
  强化项;不做也能靠 B1 的诚实并报过关,做了则实质提升证据等级。
