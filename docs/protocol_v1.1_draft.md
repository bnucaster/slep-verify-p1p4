## 2. 入域门（先于判定执行；未过门记"未构成检验"）

1. 能力门：S1 为冻结检查点因子探针复合留出精度（形状精度与三个因子
   回归 R² 负值截零后的均值）≥ 0.45；S2 为确定性口径近距导航成功率
   （逐任务固定随机流，BFS 2–6 目标）≥ ［待 8.5b］。
2. 几何门：访问区域 ĝ 谱的 log10 条件数中位 ≤ 6 且参与维数中位 ≥ 1.5。
3. 平稳门（P4 专用）：≥4 条独立长程自由运行链上 V̂ 序列的
   Gelman–Rubin R̂ ≤ 1.05。
4. 测地唯一性认证（P2、P3 用）：多起点求解，残差 ≤ 3e-3 为质检通过；
   存在相对能量差 < 0.05 且互偏差（归一化面积）> 0.028 的备选路径判
   非唯一，该端点对剔除。
5. Ŝ 仪器判据（P1 专用）：flow 主口径与 kNN（标准化 k=1）形状互证——
   逐 run 整条曲线秩相关 ≥ 0.9 且分析窗 ΔŜ 同号；不满足记该 run 的
   P1 未构成检验。

## 3. 聚合规则

每条预测按覆盖系统分别判定；标题级"支持"要求全部过门系统通过；任一
过门系统失败即该条预测计失败。S1（β-VAE）的 P4（仿射律）支线为静态
类比，只供该系统温度估计输入，不进 P4 判定。种子层面：系统 × 预测的
判定以过门种子多数（≥ 半数过门种子同向）为该格结论，过门种子不足
两个记未构成检验；逐种子结果全部随 metrics.json 报告。

## 4. 降级预案

1. 某系统温度不可辨识（仿射被拒、分半超容差、或解耦对照失败）时：
   该系统 P1 判定落在 Ŝ 与 ⟨V̂⟩，自由能 F̂_S 只作描述性曲线；P2 分位
   排序不受温度公共因子影响，照判。
2. 效用平台未检出（含数据条件不足）时：P1 母论文层记未构成检验；
   增补层改用峰值窗口（第 5 节 P1 增补判据 b）照测另列。
3. Ŝ 仪器判据不满足的 run 记 P1 未构成检验（第 2 节第 5 条）。

## 5. 失败判据（双层；母论文 4.7 节原判据照测照报，增补判据另列，
标题级通过要求两层同时成立）

### P4（自信息对势的仿射律与温度可辨识；S2 主）

- 原判据：lack-of-fit 拒绝仿射（二次项 F 检验 p ≤ 0.05 或 ΔBIC(线性
  −二次) ≥ 2），或分半温度相对差 ≥ 20%，即失败。
- 增补判据：a) 效应量层——统计拒绝（p ≤ 0.05 或 ΔBIC ≥ 2）但曲率
  效应量 ρ = |c|·SD(V̂)/|b| ≤ 0.17 时记"统计可检的估计器曲率"，不计
  失败（真仿射校准系统上 p 值判据普遍假拒绝的实测依据）；统计拒绝
  且 ρ > 0.17 计实质弯曲，失败。b) R² < 0.25 记未构成检验（低于真
  仿射校准系统的实测 R² 下侧，属仪器分辨力不足）——溯源第 1 节。c) 解耦对照（判定有效性核心，不入削减序）：均匀采样解码器
  对照与冻结解码器换策略对照，斜率随占据统计漂移超温度容差（12%）
  时按 plan_v2 第 8 节判"表观仿射不构成支持"，记未构成检验并单列
  报告。d) 盆地分段：共同斜率检验另列报告。e) 噪声操纵判向按
  docs/manipulation_signature.md（截距移动公式与 T̂ 单调上升方向）。
- 密度口径：flow 加强档为主，kNN（标准化）为消融口径并报；Î 含/不含
  体积校正双版本并报。

### P1（能量随学习下降、拟合后压缩；S1 + S2 + S3 最小版）

- 原判据：⟨V̂⟩ 效用平台后停滞或上升即失败；F̂_S 与 ⟨V̂⟩ 沿学习时间
  非增（种子噪声带内波动允许）。F̂_S 判定条件于该系统温度可辨识。
- 增补判据：a) 平台层——冻结版平台检测器（θ=1%/窗、连续 3 窗、
  斜率取绝对值双侧口径，窗长见第 1 节）检出平台时，平台后窗口
  = [平台点, min(2×平台点, 训练总长)] 内 Ŝ（flow 主口径）下降超种子
  噪声带为通过。b) 峰值窗口层（平台未检出时另列）——分析窗口改取
  [效用峰值点, min(2×峰值点, 训练总长)]，同一 Ŝ 判据照测；本层为
  本方案增补，与母论文层分开报告，不参与标题级判定。开发族实测
  提示（探索性，不进裁决）：S1 峰后 Ŝ 回升，增补层预期失败——此为
  有风险的预注册预测。c) 对照：随机标签训练预测两相结构消失；参考
  模型更换鲁棒性。d) 平凡零模型范围声明：重构项随梯度下降持续降低
  不计支持，增量只归给效用平台（或峰值）后的熵压缩。
- 检查点节奏（评估族训练配置约束）：S1 与 S2 均须均匀段每 500 步
  检查点（CAL-P1 视界条件）；S1 探针评估批量满足 σ_Û ≤ θ√W/(3√12)，
  S2 用确定性评估口径。

### P3（低梯度区审议轨迹近测地；S2 规划段）

- 原判据：低梯度区测地偏差不小于匹配的高梯度区即失败。
- 判定操作化：梯度分区从 V̂ 场预定（‖∇_ĝV̂‖_ĝ 下/上三分位，独立于
  轨迹）；端点条件化 CEM/MPC 审议轨迹（执行段隐轨迹）按穿越区域
  分组，端点距离与时长匹配；低支撑段按第 1 节规则剔除；对唯一性
  认证通过的端点对，偏差(低) < 偏差(高) 且 Mann–Whitney p < 0.01 且
  效应量 ≥ 0.0125 为通过；偏差与梯度范数正关联并报。
- 增补判据：对照规划器（随机射击、匹配平滑度变体）的偏差分布另列，
  区分规划器优化产物与地形结构。
- 地形过平（梯度三分位比的自助 CI90 下界 ≤ 1）或认证通过端点对
  不足 8（校准实测通过率 67%，8 对为 Mann–Whitney 最低可用量级）
  记检验未运行（未构成检验）。开发族实测比 1.39–1.45（CI 下界
  ≥ 1.37），预期可运行。

### P2（轨迹集中于低作用量路径；S2）

- 原判据：偏离与外部新奇不相关或负相关即失败（新奇注入步的偏离
  增量对新奇指示的逻辑回归 p < 0.01 为正关联；安慰剂：新奇时刻随机
  平移）。
- 主判据（本方案）：≥1000 条推理轨迹，每条 ≥50 条端点匹配度量口径
  主代理；观测 Â_OM 中位数低于其代理分布 Q1 的轨迹比例 > 75%。
  桥插值、时间打乱、相位随机化降为稳健性检查。
- 势项消融（判定有效性核心，不入削减序；plan_v2 第 8 节主失败判据
  原文：常数势同样"集中"即失败）：逐轨迹标准化间隙的含势/常数势
  配对差，Wilcoxon p < 0.01 且中位差 > 0 才把集中归给势结构；不满足
  即增补层失败，标题级计失败。校准与开发族证据（消融在低漂移/噪声
  比下无功效、图四梯度占比为零）提示本判据风险高——此为有风险的
  预注册，照测照报。
- 漂移梯度占比作分层变量：占比低的轨迹群失败归因于漂移结构单列。

## 6. 探索与验证分离

描述阶段（results/description/ 全部）标注探索性，不进裁决。判定只由
冻结 judge 写入 results/confirmation/metrics.json；评估阶段人的角色
只剩运行代码。评估族种子解禁以 freeze_status.frozen 置位为准
（src/slep/guard.py 机械强制）。

## 7. judge 输入契约（随协议冻结）

judge 读取 results/confirmation/<experiment>/<run_id>/judge_input.json，
schema（字段名与语义）：

- gates: {capability: {value, system}, geometry: {log10_cond_median,
  participation_median}, stationarity: {rhat, n_chains}}（按系统）；
- exp_p4: {p_lack_of_fit, delta_bic, r_squared, curvature_effect_ratio,
  slope, t_split_rel, decoupling: {uniform_decoder_slope_shift_rel,
  policy_swap_slope_shift_rel}}；
- exp_p1: {plateau_step, sigma_u, sigma_u_max, s_drop, s_band,
  v_post_trend, dual_shape: {rho, delta_same_sign}, peak_step,
  s_drop_peak_window}（逐种子）；
- exp_p3: {terrain_ratio_ci_low, mw_p, effect, low_lt_high,
  n_certified_pairs}；
- exp_p2: {frac_below_q1, n_traj, ablation: {wilcoxon_p, median_diff},
  novelty: {logistic_p, positive}, drift_fraction}。

judge 输出 metrics.json：{prediction × system: {verdict: 通过/失败/
未构成检验, gate_status, control_status, layer: {original, supplement}}}
与全量输入回显。字段缺失一律记未构成检验并注明缺失项。

## 8. 冻结程序

1. 填齐第 1 节两个 S2 槽位（任务八点五产物）；
2. 运行 python scripts/freeze_manifest.py 生成冻结清单（本文件、
   thresholds.json、judge.py、estimators 与 protocols 全部源文件的
   SHA-256）写入 docs/freeze_manifest.json；
3. 用户执行外部时间戳（公开仓库推送该提交或 OSF 存档），把时间戳
   URL 与提交哈希写入 docs/freeze_status.json 并置位 frozen；
4. 此后对冻结清单内文件的任何改动均属协议违规（守卫与审计依据
   manifest 哈希）。
