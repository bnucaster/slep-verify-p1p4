# 预注册协议 v1.3 增补：P2 × S2P 的新鲜样本外确证

## 0. 动机与定位

模拟审稿(docs/模拟审稿意见.txt,critical 1)指出:唯一通过格 P2 × S2P 来自
v1.2 修订(评估族聚合结果公开之后),其确证力弱于未接触的原始预注册。本增补
执行一次新鲜样本外确证:在一个从未使用过的种子族上重跑冻结的 v1.2 P2 管线,
判据不变。目的是检验 P2 的集中性与势结构归因是否在新实例上复现,而非评估
族 {5–9} 的偶然。

诚实边界(不夸大):本增补只消除"特定评估种子"这一层暴露;S2P 作为架构
仍是见过聚合结果后选定的,这一层暴露照旧披露,不因本增补消失。故本增补
把 P2 从"修订后预注册"提升为"修订后架构 + 新鲜预注册确证",两层如实并报。

## 1. 冻结不变量(全部沿用,零改动)

- 度量/势/密度/熵/自信息/OM 作用量估计器:v1.1 冻结件,不动。
- P2 判据与阈值:v1.2 冻结(docs/protocol_v1.2_thresholds.json 的 p2 节)——
  集中性低于代理 Q1 比例 > 0.75、势项消融配对差 Wilcoxon p < 0.01 且中位
  差 > 0、新奇关联逻辑回归 p < 0.01 且为正、安慰剂检验;逐字沿用。
- P2 管线:configs/exp_p2.yaml 的口径(1000 轨迹 × 50 度量口径代理、逐块
  缓存、势项消融同代理流配对、新奇注入 + 时移安慰剂),不动。
- 判定器:judge_v12(冻结),写 metrics.json。

## 2. 新增(仅新文件,不触冻结件)

- configs/seeds_v1_3.yaml:新增复制种子族 replication: [20, 21, 22, 23, 24]。
  这 5 个种子在本项目全程从未进入任何训练/加载/分析路径(校准 99,100;
  开发 0–4;评估 5–9;此前无 10–24 的任何使用)。configs/seeds.yaml(冻结)
  不改。
- configs/s2p_train_repl.yaml:S2P 训练配置,seed_family=replication、
  seeds_file=configs/seeds_v1_3.yaml,其余口径与 configs/s2p_train_eval.yaml
  完全一致(多步头 k=4、20k 步、逐通道方差)。新种子给出新迷宫流(迷宫由
  default_rng(seed) 生成),即新环境实例。
- configs/exp_p2_repl.yaml:P2 复制配置,指向 s2p_train_repl 与 replication
  种子族,其余(轨迹数、代理数、判据引用)与 configs/exp_p2.yaml 一致。
- scripts/ 下训练与 P2 脚本(未冻结)增 seeds_file 配置项,经 guard.family_seeds
  的 seeds_file 参数读复制族;新增运行前断言:docs/freeze_status.json 的
  v1_3.frozen 未置位则拒绝读取 replication 族(把预注册时间戳的前置性机械
  强制到脚本层,替代无法改动的冻结 guard)。

## 3. 预注册的判定(时间戳前写死)

- 运行序:冻结本增补 + configs/seeds_v1_3.yaml + 复制配置与脚本改动 →
  提交并推送公开仓库(该锚点提交即外部时间戳)→ 置位 freeze_status 的
  v1_3.frozen(记锚点与哈希)→ 才允许训练复制族 S2P 与运行 P2。
- 判据:与 v1.2 完全相同,过门种子多数(≥3/5 同向)。
- 预注册结局定义(三值,不留事后解释空间):
  - 通过:P2 × S2P(复制)= 通过,即集中/消融/新奇三层在多数复制种子成立。
    报为"新鲜样本外确证成立",P2 证据等级提升。
  - 失败:任一层在多数复制种子不成立且构成判定,报"复制未确证",据实降低
    P2 主张强度。
  - 未构成检验:复制族训练挂能力/几何门致构成判定种子不足两个,报第三值。
- 无论结局,原 v1.2 的 P2 × S2P(评估族 {5–9})判定不动、并列保留。

## 4. 冻结程序(v1.3)

1. 本增补 + seeds_v1_3.yaml + 复制配置 + 脚本改动就位,全量测试通过;
2. 提交并推送公开仓库,锚点提交即时间戳;
3. freeze_status.json 增写 v1_3 块(锚点提交、本增补 SHA-256、seeds_v1_3
   SHA-256),置 v1_3.frozen=true——脚本层据此解锁 replication 族;
4. 此后运行复制族训练与 P2,judge_v12 写判定;运行期不得再改本增补、
   seeds_v1_3、复制判据。
