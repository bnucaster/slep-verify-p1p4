## 3. 聚合规则

每条预测按覆盖系统分别判定；标题级"支持"要求全部过门系统通过；任一过门系统失败即该条预测计失败。S1（β-VAE）的 P4（仿射律）支线为静态类比，只供该系统温度估计输入，不进 P4 判定。

## 4. 降级预案

某系统温度不可辨识（仿射被拒或分半超容差）时：该系统 P1（能量下降）判定落在 Ŝ 与 ⟨V̂⟩，自由能只作描述性曲线；P2（低作用量）分位排序不受温度影响，照判。
