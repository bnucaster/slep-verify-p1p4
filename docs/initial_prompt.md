# 初始提示词

用法：在仓库根目录启动 Claude Code，把下面横线之间的内容整体粘贴为首条消息。后续任务在前一任务验收后逐条粘贴（见文末队列），不要一次派发多个。

---

先读 CLAUDE.md，再读 docs/plan_v2.md 的第 4 节（估计器层）与第 5 节（校准阶段），然后按序执行以下四件事，做完一件、产物落盘一件，再进下一件：

1. 补全包骨架：按 CLAUDE.md 目录地图建立 src/slep 各子包与 tests，使 `pip install -e ".[dev]"` 可安装；运行 tests/test_guard.py 确认评估族隔离守卫生效，并补充守卫的反向用例（用 tmp_path 复制 freeze_status.json 改为冻结置位，验证评估族放行；不得改动仓库内真实文件）。
2. 度量估计器：实现潜点处 Fisher 度量估计 ĝ 的两条路，高斯解码器 Jacobian 拉回闭式与 MC 得分协方差；写线性高斯解码器的闭式对拍测试，两路与解析 Fisher 矩阵在容差内一致才算过，容差数值在测试里注明依据。
3. 势估计：实现 V̂（潜空间 k 近邻球上解码负对数似然的均值）主操作化与编码器后验加权的第二操作化；在自构的已知势合成系统上做恢复测试，k 敏感性曲线输出到 results/calibration/。
4. 更新 PROGRESS.md 并按 CLAUDE.md 规则一（任务后进度回报）格式回报进度、健康度与信心。

边界：本任务不进入合成 Langevin 校准系统与其余估计器，那是任务二的内容；全阶段只允许种子 {99, 100}；一切阈值写"待校准"并注明来源缺口；所有文字与注释遵守 CLAUDE.md 规则二（语言禁忌）。
