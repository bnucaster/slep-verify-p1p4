## 1. 几何门重定标（6.0 → 7.0）

- 动机：v1.1 门限 6.0 溯源自 6k 步模型谱的校准可行域（5.74）加外推
  余量；20k 步训练（效用平台所需）使 S2 基线几何达 10^9.2–9.7，全体
  挂门。
- 重定标依据（results/calibration/cal_p4_ext/frontier_summary.json）：
  以 dev_v3 实测秩谱按条件数分档构造几何匹配合成系统，全链恢复实测
  ——log10 条件数 ≤ 7.0 各档 flow 主口径 T̂ 误差 1.3–8.4%（容差语境
  12% 内、R² > 下限 0.25）；7.5 档主链臂 17.2% 越容差；9.6 档 69–77%
  灾难性失败。7.0 为直接验证值，无外推成分。
- 判据与结果方向无关：恢复对象是合成系统的已知真温度。
- 披露的局限：移植实验（hyb_well）证明同一条件数下，采样各向异性
  结构（合成系统的势阱刚度谱形）可把恢复从 ~8% 翻到 ~39%，失效走
  V̂ 环节。条件数门是必要性筛查；充分性证书是逐系统几何匹配校准
  恢复。S2 基线在 9.6 档的失败对更苛刻的真实系统 a fortiori 成立，
  S2（基线版）维持挂门，v1.2 复判不改其未构成检验。

## 2. S2P 附录（S2 多步解码头变体；选项 D 产物）

- 系统定义：S2 GRU 世界模型全部不变，唯解码头输出未来 k=4 步观测
  拼接（多步教师强制 NLL，t+k ≤ T 位置计损失）。设计动机与机制：
  条件数下端来自解码器完全不用的记忆隐维（瞬时观测不依赖它们），
  多步预测头让记忆维对（预测性）观测几何可见——20k 步条件数中位从
  9.0–9.6 降到 2.95–3.09（geom_decomp/s2p_v1），全程无硬化。
- 估计器口径：ĝ 与 V̂ 用扩展解码头（decoder_mean_ext）与扩展方差
  （obs_var_ext）；密度/熵在隐态上口径不变；规划器与效用评估用单步
  语义（decoder_mean 首段切片），效用口径与 S2 完全同构。
- 入域门：能力门 0.29（随机基线池化 0.254 与 s2p_v1 训练水平——
  末三均值 0.326、峰值 0.344——中点取整，推导式与 v1.1 的 S2 完全
  相同）；几何/平稳门同表。
- 平台：冻结检测器（平滑 5、W=3）。披露：开发族池化曲线在全部平滑
  档均无平台（峰值 0.344@10500 后系统性缓降，S1 型曲线），P1 × S2P
  预期走峰值窗口增补层——有风险预注册，照测照报。
- 覆盖实验：P4/P1/P3/P2 全套，判据逐字沿用 v1.1 第 5 节；EXP-P4 的
  解耦对照、操纵签名等对照义务不变。
- 评估纪律：S2P 评估族训练严格在 v1.2 外部时间戳之后启动。评估种子
  {5–9} 曾用于 S2 基线（聚合结果已见），披露：S2P 与 S2 共享环境
  分布与种子，污染面为聚合统计量级（能力/温度/谱中位数），无逐任务
  级泄漏；此为修订路线的固有折损，计入证据等级声明。

## 3. S3 附录（小 Transformer 序列世界模型；选项 E 产物）

- 系统定义：因果 TransformerEncoder（d_model 32、2 层、2 头、ff 64）
  序列世界模型，token = 观测嵌入 + 动作嵌入 + 正弦位置码，隐状态取
  末层残差流位置输出；解码头多步 k=4（初版无多步头时残差流几何
  cond 10^28、参与维 ≈1.0，记录于 geom_decomp/s3_dev_v1；v2 实测
  4.18–4.39，geom_decomp/s3_dev_v2）。数据分布与效用口径同 S2
  （确定性近距导航，S3 穷举规划器与 S2 定稿口径同构）。
- 只跑 P1（plan_v2 第 2 节"最小版"），P4/P3/P2 不判（judge_v12
  机械强制）。
- 入域门：能力门［待 s3_u_curve 探针，同口径推导］；几何/平稳门同表。
- 平台：冻结检测器；窗长［待探针曲线定标］。
- v1.1 未操作化 S3（能力门/平台参数缺失，v1.1 judge 门函数对非 S1
  系统硬编码 S2 阈值），故 S3 一切判定只在 v1.2 下产生。

## 4. P1 双路符号判据的幅度地板（判据修订，披露）

- v1.1 判据：Ŝ 双路秩相关 ≥ 0.9 且分析窗 ΔŜ 同号，否则记仪器未过。
- 实测缺陷（EXP-P1 × S1，b1_s9）：分析窗 ΔŜ = +0.054 对 −0.018，
  两者均远小于种子噪声带（1.55），符号在噪声级变化量上无信息，
  判据把"熵基本不变"误记为仪器失效。
- v1.2 修订：max(|Δ_flow|, |Δ_knn|) < 0.25 × s_band 时视为变化量与
  零不可分，不因符号分歧记仪器未过，进入实质判定。近零降幅在
  s_drop < −s_band 判据下自然失败——修订方向使检验更严（把 NA 转为
  可能的失败），不构成对理论的放水。实现：judge_input 汇总层按此
  规则生成 delta_same_sign 字段，判定函数不改。
- v1.1 与 v1.2 判定并报；b1_s9 类情形的两版差异在论文显式列出。

## 5. 复判规则

judge_v12 对 judge_input.json 全量复判（含 v1.1 已判的 S1、S2 条目）：
S2 基线在 v1.2 门（7.0）下仍挂门（实测 9.18–9.70），P4 × S2 维持
未构成检验；S1 门判定不变（实测 cond ≤ 3.9），P1 × S1 逐 run 复判
（第 4 节地板影响 b1_s9 类）。metrics.json 由 judge_v12 写入并带
protocol_version 字段；v1.1 版判定以锚点提交存档引用。

## 6. 冻结程序（v1.2）

2. 全量测试通过后运行 freeze_manifest.py --v12 生成

   SHA-256）；
3. 用户复核本文件（检查点 3）；推送公开仓库取得外部时间戳；
4. 用户确认后在 docs/freeze_status.json 增写 v1.2 块（时间戳 URL、
   锚点提交、两文件哈希）；此后 v1.2 清单内文件不可改动；
5. S2P/S3 评估族训练与全部 v1.2 判定在时间戳之后执行。
