# 操纵签名推导：观测噪声调大后 Î–V̂ 拟合的预期变化

状态：任务二（2e）推导件，先于任何确证运行写下（docs/plan_v2.md 第 5 节
第 2 条要求预先推出签名、供确证阶段操纵检查判向）。数值验证产物见
results/calibration/cal_p4/ 下对应 run。

## 设定

合成校准系统（src/slep/systems/cal_langevin.py）：状态 z 由已知温度 T 的
Langevin 采出，观测按 x = μ(z) + b(z) + ε 生成，μ 为解码器均值，b 为
解码器族外偏置，ε ~ N(0, σ_x² I_D) 为观测噪声，D 为观测维数，σ_x 为
噪声标准差。解码器假定方差为 σ_dec²（固定，不随操纵变）。

操纵：把观测噪声从 σ_x 调大到 σ_x'，其余全部不动——状态样本、解码器、
密度估计与度量估计的输入都不变，只有 V̂ 读到的观测变吵。这对应确证阶段
的估计层操纵检查：轨迹冻结后对观测重加噪、重算 V̂。

## 效应一：V̂ 整体上移，截距移动

V̂ 的估计对象（k 近邻球稠密极限）是

    V_est(z) = V(z) + D·σ_x²/(2σ_dec²) + c₀

V(z) 为动力学势，c₀ = (D/2)·log(2πσ_dec²) 为高斯配分常数。σ_x → σ_x'
时全体查询点同加

    Δ = D·(σ_x'² − σ_x²)/(2σ_dec²)

Î 不依赖 σ_x（密度估计只用状态样本，度量只用解码器），故拟合
Î = a + b·V̂ 中斜率的总体对象不变，截距变为 a − b·Δ。

## 效应二：斜率衰减，T̂ 上升

V̂ 的单点估计噪声方差（推导同 src/slep/systems/selfcheck.py 的
noise_se，加权到本系统）为

    Var_noise(z) = ( σ_x²·E‖m(z)‖² + D·σ_x⁴/2 ) / (σ_dec⁴·k)

m(z) 为邻居观测对解码均值的残差（本系统内 E‖m‖² ≈ 2σ_dec²·V(z) 加邻域
离散项），k 为近邻数。回归元（V̂ 在横轴）含零均值噪声时，OLS 斜率期望
按经典衰减因子缩小：

    E[b̂] ≈ b_true·λ，λ = Var_z(V_est) / ( Var_z(V_est) + mean_z Var_noise )

Var_z(V_est) 为真势值跨查询点的方差，mean_z Var_noise 为噪声方差的均值
（异方差用均值近似，推导前提之一）。于是

    T̂ = 1/b̂ ≈ T/λ ≥ T，且随 σ_x 单调上升。

Î 自身的估计噪声在纵轴，不衰减斜率，只加宽残差带、压低 R²。

## 判向签名（预注册用）

对"轨迹冻结、观测重加噪"的操纵，管线健康时应同时看到：

1. V̂ 样本均值上移量与 Δ = D·(σ_x'²−σ_x²)/(2σ_dec²) 一致（校准容差内）；
2. 拟合斜率按 λ 预测衰减，T̂ 相应上升；
3. lack-of-fit 不新增结构（二次项仍不显著）。

若确证系统在该操纵下斜率反而上升（T̂ 下降），或截距移动方向与 Δ 相反，
说明表观仿射由噪声结构而非势结构驱动，该系统 P4（仿射律）判定无效。

## 适用边界

推导只覆盖估计层操纵（样本与解码器冻结）。若操纵改在系统层（训练时
就加大观测噪声，模型重新平衡），密度与度量都会变，两轴同动，上述
签名不适用；plan_v2 第 5 节第 2 条"T̂ 未必朴素上升"的告诫针对的正是
后一情形。确证阶段的操纵检查须写明采用估计层口径。
