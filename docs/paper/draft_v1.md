# 语义最小能量原理四条预测的预注册实证检验：一项通过、其余未构成检验的三值记账

草稿 v1（任务十二 / M6）。全部数字出自 results/ 下产物文件，出处随文标注；
判定由冻结判定代码写入 results/confirmation/metrics.json，本文只是转述。
证据等级两档并报：协议 v1.1（原始预注册，锚点提交 f7f7910）与协议 v1.2
（披露性修订，锚点提交 27df5af），见第 6 节。

## 摘要

《语义最小能量原理》（下称母论文）第 4.7 节给出四条可反驳预测：P1，
能量随学习下降、拟合后压缩；P2，推理轨迹集中于低作用量路径；P3，低梯度
区审议轨迹接近测地线；P4，自信息对势呈仿射关系且温度可辨识。本文在三类
小型系统（β-VAE、循环世界模型及其多步解码头变体、小型 Transformer 序列
世界模型）上对这四条预测执行预注册检验：判定阈值全部溯源到校准产物，
判定代码在见到评估数据前冻结并取得公开仓库外部时间戳，每格结论取三值
（通过 / 失败 / 未构成检验）。结果：P2 在世界模型变体上通过——五个评估
种子全票，观测轨迹的 Onsager–Machlup 作用量全部低于其端点匹配代理分布的
下四分位，集中性经势项消融归因于势结构（配对差正向，Wilcoxon 符号秩
p 介于 1e-12 与 7e-34），新奇注入关联显著且安慰剂检验干净。P4 的表观
仿射被解耦对照否定支持资格（解码器换均匀占据训练后斜率漂移 0.16–0.30，
超过预注册容差 0.12），且曲率效应量在全部种子超过实质弯曲上限；P1 的
效用平台前提在三种架构共 13 个过门训练实例上均不成立，效用峰值后熵普遍
上升；P3 因测地求解残差质检在估计度量上系统性不达标，认证端点对不足，
检验未运行。检验过程本身产出四项仪器发现：训练长度与度量可测性的互斥、
多步解码头对隐空间几何的量级修复、仪器可行性并非条件数的单变量函数、
残差质检量表在解析度量与估计度量之间不可比。

## 1. 引言

母论文提出：一个带效用约束的学习系统在学习尺度上沿自由能下降，在推理
尺度上其内部状态近似服从以语义势为漂移的 Langevin 动力学。它的第 4.7 节
（预测协议）把该主张压缩为四条可分别反驳的预测，并要求检验遵守预注册
纪律。本文是该协议的执行记录。

四条预测的操作化含义：

- P1（能量随学习下降、拟合后压缩）：沿训练检查点，平均势 ⟨V̂⟩ 与熵 Ŝ
  在效用达到平台后继续下降——效用不再涨了，内部表征还在压缩。
- P2（低作用量集中）：推理轨迹的路径作用量显著低于同端点、同长度、同
  速度分布的随机代理路径，且这种集中归因于势梯度项——把势换成常数后
  分辨力应显著变差。
- P3（低梯度区近测地）：势场平缓区域的审议轨迹比陡峭区域更接近同端点
  测地线。
- P4（仿射律与温度）：状态的自信息 Î 对势 V̂ 线性（Î ≈ a + b·V̂，a 为
  截距，b 为斜率），温度按 T̂ = 1/b 辨识且分半一致。

检验的方法论骨架有三条。其一，阈值溯源：一切判定阈值来自校准阶段在
已知真值合成系统上的实测，代码中的每个常量注释指向推导产物。其二，
判定冻结与外部时间戳：判定代码与阈值表在评估族数据被触碰之前冻结，
以公开 Git 仓库提交哈希作时间戳；评估阶段人的角色只剩运行代码。其三，
三值记账：未通过入域门（能力、几何、平稳性、测地唯一性）的格记
"未构成检验"，与"失败"分开统计——门外的失败没有反驳力，门外的通过
也没有支持力。

## 2. 系统与估计器

### 2.1 测试系统

- S1：β-VAE（变分自编码器，β 为 KL 项权重）在 dSprites 数据集上，潜维
  8，β ∈ {1, 4}。真值因子已知，效用取因子探针复合精度（形状分类精度与
  尺度、横纵位置三个回归 R² 负值截零后的均值）。
- S2：GRU（门控循环单元）世界模型在程序生成迷宫导航环境上，隐维 16，
  双通道局部观测（墙体与目标指示），逐通道固定方差高斯解码器。效用取
  确定性口径的近距导航成功率（固定任务清单、逐任务固定随机数流，重复
  噪声为零）。推理轨迹是隐状态沿真实执行的演化。
- S2P：S2 的多步解码头变体（协议 v1.2 附录）——解码器输出未来 4 步
  观测拼接，其余全部不变。设计动机见第 5.2 节仪器发现。
- S3：小型因果 Transformer 序列世界模型（2 层，隐宽 32，2 头），数据
  分布与效用口径同 S2，隐状态取末层残差流，多步解码头同 S2P。按计划
  只检验 P1。

### 2.2 估计器

度量 ĝ 取高斯解码器的 Fisher 信息拉回：

    ĝ(z) = J(z)ᵀ Σ⁻¹ J(z)

其中 z 为潜状态（维数 8 或 16），J(z) 为解码器均值对 z 的 Jacobian
矩阵（观测维 × 潜维），Σ 为解码器观测噪声的对角协方差。它度量的是
"潜状态往某方向挪动一点，观测分布变化多少"。

势 V̂(z) 取 z 的 k 近邻（k=32）样本上解码负对数似然的均值；密度双路
（k 近邻估计与自研 RealNVP 归一化流）互证，熵 Ŝ 同法双路；自信息含
体积校正：

    Î(z) = −log p̂(z) + (1/2)·log det ĝ(z)

p̂ 为潜态密度估计。校正项把坐标密度换算为相对流形不变体积的密度，
缺了它仿射律的两轴依赖参数化选择。路径作用量取 Onsager–Machlup 主项
的离散化：

    Â_OM = (1/4T)·Σ_t ‖Δz_t/Δt + ĝ⁻¹∇V̂‖²_ĝ · Δt

Δz_t 为相邻状态差，T 为温度（排序统计对公共正因子不变，取 1），
‖·‖_ĝ 为 ĝ 度量下的范数。它累计的是"路径速度对负势梯度漂移的偏离"
的平方代价。全部估计器在接入实验前通过合成真值自检（线性闭式对拍、
解析熵恢复、合成 Langevin 恢复）。

### 2.3 校准与仪器可行域

校准阶段构造几何匹配的合成 Langevin 系统：已知势、已知度量、已知温度，
谱形匹配到真实系统试点实测。全链恢复实测确定了两件事。其一，密度主
口径：k 近邻密度在 16 维匹配几何上温度误差 26–33%，归一化流口径把
误差压到 1.2–6.0%（results/calibration/cal_p4/）——流口径成为冻结主
口径。其二，可行域边界（results/calibration/cal_p4_ext/frontier_summary.json）：
以 20k 步真实谱按条件数分档重跑恢复，log10 条件数中位 ≤ 7.0 各档温度
误差 1.3–8.4%，7.5 档主链臂 17.2% 越出容差语境（12%），9.6 档 69–77%
灾难性失败。判定用的几何门由此定标（v1.1 取 6.0 含外推余量，v1.2 修订
为直接验证值 7.0）。

## 3. 协议与判定机制

协议 v1.1 于评估数据触碰前冻结（17 个文件 SHA-256 清单，公开仓库锚点
提交 f7f7910）。评估中期发现几何门与训练长度存在系统性冲突（第 5.1
节），据此执行了一次披露性修订 v1.2（22 文件清单，锚点提交 27df5af）：
几何门重定标、S2P 与 S3 附录、P1 双路符号判据加幅度地板。修订判据全部
来自合成真值恢复与开发族测量，不依赖评估族上预测本身的成败方向；v1.1
判定存档于其锚点提交，v1.2 全量复判，两版并报。判定由冻结判定代码
（judge_v12）写入 metrics.json，聚合规则为过门种子多数（半数以上同向），
构成判定的种子不足两个记未构成检验。

### 4.2 P2 通过的证据链（主结果）

系统 S2P，五个评估种子，每种子 1000 条推理轨迹，每条配 50 条端点匹配
的度量口径平滑随机代理（长度与 ĝ 度量下速度分布匹配；欧氏口径代理在
校准中被证明因动能失配而给出虚假满分离，弃用）。三层判据全部通过
（results/confirmation/exp_p2/eval_v1/）：

- 集中性：观测轨迹 Â_OM 中位数低于其代理分布下四分位的比例，五种子
  均为 1.000（判定线 0.75）；标准化间隙中位 0.45–0.49。
- 势项消融（判定有效性核心）：同批路径把 ∇V̂ 置零重打分，逐轨迹配对
  差（含势间隙减常数势间隙）中位 +0.0021 至 +0.0036，Wilcoxon 符号秩
  p 介于 1.0e-12 与 6.9e-34——含势版本的分辨力系统性更高，集中可归因
  于势结构。此判据在预注册时被标注为高风险（开发族基线 S2 上梯度占比
  为零、消融无功效），在 S2P 上获得功效；与此同步，经验漂移的梯度占比
  从基线的 0.000 变为 0.04–0.11。
- 新奇关联与安慰剂：新奇注入步（迷宫拓扑切换）的逐步作用量增量对新奇
  指示的逻辑回归，似然比 p 介于 5.3e-07 与 3.3e-04 且系数为正；注入
  时刻随机平移的安慰剂全部不显著（p 0.17–0.93）。

按预注册的措辞规范，该格的支持只能写成：观测与假说一致，且超出平凡
解释的增量为——集中性不能由动能匹配的随机路径复现（代理已匹配速度
分布），也不能由常数势复现（消融配对差正向显著）。

### 4.3 P4：表观仿射为何不构成支持

系统 S2P 上仪器分辨力充分：R² 0.464–0.589（下限 0.25），斜率跨种子
一致（0.023–0.026，对应 T̂ 38.4–43.2），分半温度相对差 0.028–0.109
（容差 0.20），多链平稳性 R̂ ≤ 1.003。但两层判据同时反对：

- 解耦对照（判定有效性核心）：把解码器在位置占据均匀化的数据上重训、
  访问分布不变，斜率相对漂移 0.159–0.298，五种子全部超过容差 0.12
  ——表观仿射的相当部分来自"解码器在常访问区拟合更好"，按预注册
  规则记"表观仿射不构成支持"。作为对照的对照：换探索策略（冻结解码
  器）斜率几乎不动（0.001–0.091），操纵检查的截距移动与预推公式吻合
  （比值 0.99–1.01），说明失败是解码器占据耦合，而非管线故障。
- 曲率：lack-of-fit 统计拒绝（p ≤ 1e-26）且曲率效应量 ρ = |c|·SD(V̂)/|b|
  为 0.175–0.412，全部超过实质弯曲上限 0.17（c 为二次项系数，SD(V̂)
  为横轴标准差）。即便解耦通过，判定也是失败而非通过。
- 另列：盆地分段的共同斜率检验在五种子全部强拒绝（p ≤ 1e-62）；异
  种子度量副本使斜率漂移 0.46–0.68，仿射结构强依赖模型自身度量。

基线 S2 的 P4 在两版协议下都挂几何门（20k 步条件数中位 9.18–9.70）。

### 4.4 P1：平台前提与峰后熵升

三种架构、13 个过门训练实例，效用平台无一按冻结检测器检出：S1 逃逸
实例两个晚逃逸（尾段仍陡升，运行期窗长规则给出超视界窗长）、一个早
逃逸实例检出平台但熵变化量与噪声带相比接近零；S2P 与 S3 各五种子为
峰后缓降或窗间波动形态。母论文层前提不成立，全部记未构成检验。

增补的峰值窗口层（预注册中另列、不进标题判定）给出方向一致的反向
信号：效用峰值点到其两倍位置的窗口内，Ŝ 变化量在 S1 为 +1.3 与 +1.9
nats、S2P 为 −0.9 至 +9.3（五分之四为正）、S3 为 +0.85 至 +15.4 全正
——效用到顶后熵普遍上升而更少下降。该信号在开发族即被观测到并预注册
为"预期失败的风险预测"，评估族在三种架构上复现了它。S3 上双路熵
（流与 k 近邻）秩相关 0.999–1.000，仪器一致性最佳，信号最不含糊。

### 4.5 P3：检验未运行的原因

地形门健康（高/低梯度三分位中位比的自助 CI90 下界 1.87–1.94，地形有
可检结构），但测地求解的残差质检把每种子 74–80 对候选剔除到只剩 1–3
对认证（下限 8）。根源：残差阈值 3e-3 定标于解析光滑的合成度量，估计
的 MLP 解码器度量上双精度、能量归一、加大迭代预算后实测只能到 ~0.26
量级。P3 判定为检验未运行，残差量表的不可比性入第 5.4 节。

## 5. 仪器发现

### 5.1 训练长度与度量可测性的互斥

S2 基线的 log10 条件数中位沿训练单调增长：500 步约 2.4–2.9，6000–8000
步穿过 6.0，20k 步达 9.0–9.6，无饱和迹象（results/description/geom_decomp/
dev_v3/）；而效用平台出现在 15500 步。学好目标预测要求把解码器推进
sigmoid 饱和区，饱和使部分隐维对观测几何不可见——效用平台区与仪器可
测区（≤7.0）在该系统上不相交。等方差口径对照证明条件数与逐通道方差
设计无关，全部来自解码器 Jacobian 退化。

### 5.2 多步解码头的量级修复

诊断把条件数下端归因于解码器完全不使用的记忆隐维（瞬时观测不依赖
它们）。让解码头输出未来 4 步观测拼接后，记忆维对预测性观测几何可见：
S2P 条件数中位降到 2.95–3.09（六个数量级），全程无硬化，效用不受损
（评估族峰值 0.368 对基线 0.329）；同一修复把 S3 从条件数 10^28、参与
维 1.0 的近秩一退化拉回到 4.2–4.4。漂移梯度占比从 0.000 变为 0.04–0.11，
P2 的势项消融由无功效变为强功效——P2 的通过实质上是这个仪器修复
解锁的。

### 5.3 可行性并非条件数的单变量函数

可行域边界细化中的移植实验（results/calibration/cal_p4_ext/hyb_*）：
同一条件数（5.74 档）下，仅把合成系统的势阱刚度谱从对数等距梯子换成
含近重复值的随机抽取，温度恢复误差从约 8% 恶化到约 39%，失效走势估计
环节。度量谱统计相同的两个系统可行性可以截然不同——条件数门是必要性
筛查，充分性证书只能来自逐系统的几何匹配校准恢复。

### 5.4 残差量表与判据的可移植性

两条判据在从合成定标系统移植到真实估计系统时量表失效：测地残差
（第 4.5 节）与 P1 双路符号判据（近零变化量上符号分歧无信息，v1.2 加
幅度地板修正，方向使检验更严）。预注册阈值的定标系统与应用系统之间
的量表对齐，应作为校准阶段的显式检查项。

## 6. 证据等级与局限

- 两版协议：v1.1 为原始预注册；v1.2 修订发生在评估族聚合结果公开之后，
  其下产出的判定（含唯一的通过格 P2 × S2P）属"修订后预注册"等级。
  修订判据不看预测成败方向（几何门重定标只依赖合成真值恢复），且 S2P
  的设计只使用开发族数据，但评估种子 {5–9} 曾用于基线 S2 的实验，
  聚合统计量级的信息暴露存在，逐任务级泄漏不存在。此为修订路线的固有
  折损，如实计入。
- P2 通过格的边界：势项消融的配对差中位数值上小（0.002–0.004 标准化
  间隙单位），显著性来自 1000 对的一致方向；新奇关联是一致性检查而非
  机制证明；温度取 1 的排序口径下 P2 不依赖 T̂ 辨识，但也因此不能
  反过来支持 P4。
- 范围声明（协议第 13 节）：实测的能量是解码器定义的重构代价的无量纲
  化，它是否配称"语义"正是待检验之事，本文不预设；非平稳环境与跨
  模态预测（P5）在本篇范围外。
- 系统规模小（潜维 ≤ 16、单机 CPU 量级），结论的外推性未经检验。

## 7. 结论

四条预测在可测范围内的记账：一条通过（P2，低作用量集中，含势结构
归因），一条在有分辨力的仪器下被两层判据反对支持资格（P4），一条的
前提在三种架构上不成立且反向信号稳定复现（P1），一条因仪器量表不可比
而未运行（P3）。对母论文的含义：推理尺度的"轨迹集中于低作用量路径"
获得了超出平凡解释的支持；学习尺度的"拟合后压缩"在本文全部系统上
没有出现，峰后熵上升是需要理论回应的稳定现象；仿射律与温度辨识在
当前估计器技术下无法与解码器占据效应解耦，其检验有效性依赖尚不存在
的仪器改进。
